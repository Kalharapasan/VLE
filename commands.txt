================================================================================
UNIVERSITY MANAGEMENT SYSTEM (UMS) - COMPLETE SETUP COMMANDS
================================================================================

PREREQUISITES:
- PHP >= 8.1
- Composer
- Node.js (v16+)
- NPM
- MySQL (XAMPP/WAMP/Laragon)
- Git

================================================================================
STEP 1: DATABASE SETUP (MySQL)
================================================================================

Open your MySQL client (phpMyAdmin or MySQL CLI) and run:

CREATE DATABASE IF NOT EXISTS vle;
CREATE DATABASE IF NOT EXISTS vle_test;

Or via XAMPP MySQL:
/c/xampp/mysql/bin/mysql.exe -u root -e "CREATE DATABASE IF NOT EXISTS vle;"

================================================================================
STEP 2: BACKEND SETUP (Laravel)
================================================================================

cd students_backend

# Install PHP dependencies
composer install

# Create .env file from example
copy .env.example .env
(On Linux/Mac: cp .env.example .env)

# Edit .env file and set:
# DB_DATABASE=vle
# DB_USERNAME=root
# DB_PASSWORD= (leave empty if no password)

# Generate application key
php artisan key:generate

# Run database migrations
php artisan migrate --force

# (Optional) Seed dummy data
php artisan db:seed

# Start Laravel development server (port 8000)
php artisan serve --port=8000

# Server will start at: http://127.0.0.1:8000

================================================================================
STEP 3: FRONTEND SETUP (React + Vite)
================================================================================

# Open a NEW terminal window and navigate to frontend folder
cd students_frontend

# Install JavaScript dependencies
npm install

# Create .env file for frontend (if not exists)
# The .env file should contain:
# VITE_API_URL=http://127.0.0.1:8000/api

# Start React development server
npm run dev

# Frontend will start at: http://localhost:5173 (or similar port)

================================================================================
STEP 4: TEST THE CONNECTION
================================================================================

# Test backend API (in a separate terminal):
curl http://127.0.0.1:8000/api/admin/count

# Expected response: {"admin_count":0}

# Test frontend is accessible:
# Open http://localhost:5173 in your browser

================================================================================
NOTES:
================================================================================

1. Make sure MySQL is running before starting the backend
2. The frontend .env file should have: VITE_API_URL=http://127.0.0.1:8000/api
3. CORS is already configured in backend to accept requests from any origin
4. All API endpoints return JSON format
5. For file uploads, use multipart/form-data
6. To update resources, use POST with _method=PUT (for form-data)
7. Sanctum is used for API authentication

================================================================================
TROUBLESHOOTING:
================================================================================

1. If "vendor folder not found":
   Run: composer install

2. If "database does not exist":
   Create the database in MySQL: CREATE DATABASE vle;

3. If CORS errors:
   Check that backend cors.php has: 'allowed_origins' => ['*']

4. If frontend can't connect to backend:
   - Check backend is running on port 8000
   - Check frontend .env has correct VITE_API_URL
   - Restart both servers after changing .env files

5. If "Artisan command not found":
   Make sure you're in the students_backend directory
